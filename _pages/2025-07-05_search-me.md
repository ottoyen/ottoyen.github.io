# OpenAI Deep Research: 介紹並分析國泰Otto。



# **Otto（顏勝豪）在國泰金控的公開資料分析**

## **1. 職涯經歷**

- **學歷背景與早期經歷：** 顏勝豪擁有資訊相關碩士學位，早在2005年即完成以數位學習為主題的研究 。他累積超過15年的軟體開發經驗及12年的團隊管理經驗 。職涯初期歷經從**程式設計師**、**系統設計師**、**系統分析師**到**技術經理**等紮實養成與晉升歷程 。在進入國泰之前，他曾帶領專案開發團隊承接多元領域的系統專案，包括外商銀行交易系統、商業智慧（BI）分析平台，以及警政情資整合分析平台與大數據分析平台的架構設計與建置 。
- **加入國泰與角色發展：** 顏勝豪於2020年起參與國泰金控為期七年的雲端轉型計畫 。他進入國泰金控「數位數據暨科技發展中心」（俗稱「數數發中心」）擔任**雲端技術架構師**，負責執行整個集團的雲端轉型計畫並擬定集團上雲策略 。隨著雲端專案的推進，他的職務職級也隨之提升，現任**國泰金控雲端策略發展部協理**（Senior VP/Assistant GM），成為該金融集團推動雲端與數位轉型的核心技術主管 。
- **目前職責：** 身為雲端策略發展部協理，顏勝豪肩負**跨子公司的雲端佈局統籌**，領導團隊落實國泰集團的雲端升級藍圖 。他的主要任務包括執行集團雲端轉型、制定上雲標準與治理政策，以及在銀行、人壽、產險、證券等子公司推廣雲端技術落地應用  。在他的帶領下，國泰金控各事業體得以協同推進數位化轉型。

## **2. 技術專長**

- **雲端架構與雲原生技術：** 顏勝豪專精於企業級雲端架構設計與部署，特別擅長**混合雲**與**多雲**架構。在金融業嚴格的監管環境下，他為國泰打造出安全合規的雲端基礎：透過專線串接確保資料傳輸不經公共網路、採取資料中心延伸的雲端架構實現嚴密的環境隔離，同時導入自動化部署實現雲端與本地環境的一體化 CI/CD 流程，避免人工操作失誤造成敏感資訊外洩 。他也熟悉容器技術（如 AWS ECS/EKS 等），將傳統應用容器化以利於在多種環境即時運行，提高系統部署的彈性 。
- **DevOps 與基礎設施即程式碼 (IaC)：** 顏勝豪在推動DevOps文化與工具方面經驗豐富，大力推行**Infrastructure as Code**自動化技術來管理雲端基礎設施 。他主導國泰率先導入 IaC，透過程式碼而非人工來配置和部署雲端資源，確保每次環境佈署的一致性與可追溯性 。此舉大幅提升了部署速度與品質：只需一鍵即可迅速建置複雜的雲端環境，並能透過版本控管與 **Policy as Code** 機制事前檢查安全性，確保各環境配置符合金融業合規要求 。他強調將雲端部署「程式碼化」的好處，不僅實現**Security/Policy/Compliance as Code**，更便利稽核追蹤，每次變更都有版本紀錄，符合金融業嚴格的稽核需求 。
- **架構設計與大數據技術：** 他的技術專長還包含**企業系統架構設計**與**大數據平台**構建。在先前經歷中，他為警政單位打造情資整合分析平台，並領導建置國泰內部的大數據分析平台 。這些經驗讓他在資料庫、資料分析、生態圈整合等方面具備深厚的實作能力。此外，他熟悉領域驅動設計（DDD）等架構方法，曾在 DDD 技術年會上分享金融業導入 DDD 的應用實例，展現他將前沿架構理念應用於金融IT系統的能力。
- **生成式 AI 與自動化工具：** 面對新興的 AI 浪潮，顏勝豪積極探索**生成式人工智慧**在雲端架構與開發流程中的應用。他相信未來的人機協作是關鍵，熱衷於將 AI 技術融入工作以提升效率 。例如，他帶領團隊開發了內部工具「**Smart Archie**」，結合大型語言模型(LLM)與 Diagram-as-Code 技術，自動生成雲端架構圖。 。透過 Smart Archie，架構師只需以對話方式輸入需求，即可在30秒內產出符合Cathay 6R方法論和公司規範的架構圖，將過去人工繪圖3-4小時的工作縮短到2分鐘以內，大幅提升架構設計的一致性與產出效率  。此外，他也關注AI輔助開發工具的應用，鼓勵團隊使用如 GitHub Copilot 等AI編碼助手來優化程式撰寫、自動化測試流程，藉此**加速開發周期**並保持代碼品質（顏勝豪本人亦善用 NotebookLM 等AI工具進行知識管理與學習，加速自身與團隊的成長 ）。

## **3. 對金融科技的影響**

- **引領金融業上雲風潮：** 顏勝豪被視為將雲端技術引入金融場景的**先行者**。在金融監管單位開放「金融三業委外上雲辦法」後，國泰金控成為產業中**首家獲准全面上雲的金控業者** 。他主導自2020年起的集團雲端轉型計畫，訂下在5年內讓100套金融應用上雲的目標 。截至2024年底已成功將超過70套核心系統搬上雲端，大規模上雲的成果有目共睹 。這一創舉證明了金融業在嚴格法規下依然可以大規模採用雲端，**實質改變**了業界對於雲端應用於金融服務可行性的觀念。透過他的推動，國泰不僅降低了既有系統的技術債務、提升營運效率，更為新金融服務的創新提供了靈活試驗的雲端環境  。
- **策略與方法論的創新：** 在顏勝豪的策劃下，國泰自行研發出適用於金融業的大規模上雲遷移方法論 **「Cathay 6R」**。該方法論借鑒了 Gartner 的5R與 AWS的7R雲移轉模型，並結合國泰自身IT現況予以調整 。Cathay 6R 將系統遷移路徑劃分為 Rehost、Replatform、Refactor、Rewrite、Replace、Retain 六種類型，以對應IaaS/PaaS/SaaS不同上雲模式 。顏勝豪表示，透過自建這套方法論，更能貼合國泰金融上雲的實際情境與需求 。此一創新策略不僅被應用在國泰內部（協助各子公司評估並選擇最適遷移路徑），也為金融業界提供了**雲端轉型的標竿範例**，許多同業在規劃上雲時參考了國泰的經驗。
- **技術落地與痛點克服：** 顏勝豪對金融科技最大的貢獻之一，是打通了傳統金融IT邁向雲端道路上的技術與觀念障礙。他率先在國泰導入**混合雲架構**，確保雲端部署在符合監管要求的前提下進行，解決過去金融機構擔心資料外洩與網路安全的痛點 。「雲端轉型會面臨許多新課題，例如資料加密、金鑰管理、日誌集中、雲服務控管等，」顏勝豪曾指出這些金融上雲的挑戰 。為此他採取了一系列對策：利用專有網路與雲端服務商協作，加強雲端環境的**資安防護與合規機制**；導入 IaC 自動化部署來消除人工錯誤並建立**雲端治理**的稽核軌跡 。這些措施使國泰在上雲後依舊保持對安全與法規的掌控，同時大幅提高了IT基礎建設的供應效率。其成功經驗證明金融業可以藉由技術創新來滿足監管與創新的雙重要求，在業界引發廣泛迴響 。
- **觀念影響與產業示範：** 在顏勝豪的推動下，國泰金控的雲端轉型被視為金融業數位創新的里程碑。他強調**「上雲不是僅將VM搬到雲端」**，而是需要搭配應用現代化與持續優化，否則成本效益難以顯現  **。這樣的觀點讓許多金融從業人員開始重新思考上雲策略的重要性。透過各種公開分享，顏勝豪倡導如**雲原生架構**、**敏捷交付**、**DevOps文化**在金融場景的價值，影響了不少傳統銀行與保險從業者的思維轉變。例如，國泰的經驗顯示出將傳統應用改寫為雲原生服務後，雲端運行成本可大幅下降超過一半 （相較於直接移植上雲的方式），這些實績數據進一步說服產業投入雲端優化的必要。整體而言，他在國泰的實踐為金融科技領域**樹立了標竿，帶動產業朝更開放、彈性的技術架構邁進。
## **4. 領導風格**

- **RPG 式成長思維：** 顏勝豪以獨特的「**RPG遊戲練功**」理念來形容自己的帶隊風格。他相信職涯和團隊成長就像角色扮演遊戲一樣，需要不斷**打怪升級**：透過一次次解決難題來累積經驗值 。他鼓勵團隊成員勇於接受挑戰、敏捷應對變局，在實戰中提升技能。同時，他強調每完成一個專案就如同通過一個關卡，要總結經驗並分享到整個團隊，讓大家共同進步 。這種寓工作於遊戲的思維營造出積極進取又樂於互助的團隊文化。
- **重視學習分享與軟實力：** 在他的領導下，團隊內部形成良好的**知識分享**風氣。顏勝豪本人堅持終身學習，並將這種態度傳遞給同仁：他經常組織讀書會、經驗分享會，確保技術心得在團隊內部自由流動 。除了精進硬技術，他也特別強調培養**溝通協作、創造力、批判性思考**等軟實力，認為在AI時代這些能力更加關鍵 。他在團隊中推動**雙向溝通**的氛圍，鼓勵工程師提出創新想法並勇於挑戰現狀，同時培養他們從全局視角思考問題的能力。這種技術與軟技能並重的方針，使團隊能在快速變遷的金融科技領域保持學習敏銳度與應變能力 。
- **教練式領導與夥伴合作：** 顏勝豪的角色不僅是技術主管，更像是團隊的**教練與顧問**。在推動國泰上雲的進程中，他經常親自指導各子公司的IT團隊，扮演內部顧問協助評估雲端架構，亦如教練般帶領他們克服轉型過程中的心態與技術障礙 。這種「亦師亦友」的領導風格被視為打造高效雲端團隊的關鍵 。同時，他善於**跨部門協作**，會主動聯繫業務單位溝通需求，並與風險合規等部門密切合作，確保技術方案符合業務目標和監理規範。對外方面，顏勝豪也積極與產業**異業夥伴**合作，例如與雲服務商共同研討解決方案，或參與監管機關的諮詢會議推動產業規範鬆綁 。他曾分享國泰在挑選新創合作夥伴時的標準與心得，表示願意引入外部創新力量來加速內部數位創新 。總體而言，他的領導展現出開放共創的格局，帶領技術團隊與內外部伙伴緊密協作，朝共同目標前進。
- **以身作則推動創新：** 作為技術領袖，顏勝豪樂於嘗試新技術並以實際成果來帶動團隊。例如在AI新工具方面，他往往親自上手測試各種開發者助理（如 NotebookLM、各類程式碼生成工具），將有成效的工具引入團隊日常工作 。當團隊成員看到主管親自應用並取得顯著效率提升，也更願意跟進學習，形成良性循環。在他的倡導下，國泰技術團隊對新技術的接受度很高，勇於成為金融圈中**第一批吃螃蟹的人**。這種以身作則、鼓勵創新的領導作風不僅提升了團隊士氣，也讓國泰在金融科技創新上始終保持業界領先地位。

## **6. 網路評價與觀感**

- **業界意見領袖形象：** 在台灣金融科技圈，顏勝豪普遍被視為引領金融數位轉型的技術意見領袖之一。他多次代表國泰出現在重要論壇與媒體版面上，與其他企業高層一同討論產業未來。例如2025年的德勤策略生態峰會（E&A Summit）上，他與中國信託、凱基金控等協理/副總級人物並列為座談嘉賓，為企業分享AI創新的落地策略 。這種曝光彰顯他在產業中的專業地位，說明業界對其專業見解的重視程度。由於他長期專注於金融上雲與FinTech創新，網路社群中時常將他與金融科技創新趨勢聯繫在一起，認為他是**金融數位轉型的重要推手**。
- **媒體報導與口碑：** 科技媒體經常引用顏勝豪的經驗來說明金融科技發展狀況，對其評價多為正面積極。例如，《iThome》等媒體在報導國泰上雲案例時，詳細介紹了顏勝豪如何克服金融業上雲的種種挑戰，包括資安、合規與組織調整等，藉此凸顯他在該領域的專業洞見 。AWS 官方網站亦曾以專文分享國泰採用 IaC 強化雲端治理的案例，其中多處引述了顏勝豪對雲端轉型的看法  。這些報導讓他在技術圈中建立了**實幹型專家的口碑**。網路上一些技術討論串和部落格也將他的做法當作成功範例來分析，如Medium上有技術顧問撰文討論國泰的6R雲轉型方法時，就引用了顏勝豪的觀點來說明該方法論如何貼近實務 。
- **社群評價：** 在開發者社群與論壇中，顏勝豪被不少人奉為**雲端金融的先行者**。許多同行認為他敢於突破金融業的傳統框架，引入新技術的魄力值得肯定。有工程師在社群聚會後分享心得時提到，從顏勝豪的演講中深刻體會到大型金融機構上雲的複雜度，以及他帶領團隊迎難而上的決心，因而對其 **leader 風範**印象深刻（來源：社群活動參與者心得）。同時，他樂於在社群中回答提問、交流經驗的作風也獲得好評，許多技術人員視他為平易近人的前輩。總體來說，網路輿論對於Otto顏勝豪的觀感是非常正面的：將其視為**既有遠見又腳踏實地**的技術領導者，認為他的分享為金融業帶來了創新思維，對年輕技術人也具有啟發性。正因如此，顏勝豪在台灣金融科技技術圈已累積相當影響力，被廣泛認可為業界的KOL級人物。
